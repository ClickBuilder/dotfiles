# qs-player

Музыкальный плеер для [Quickshell](https://quickshell.outfoxxed.me/) на QML. Работает поверх всех окон (Wayland overlay layer), управляется полностью с клавиатуры. Воспроизводит локальную музыку и YouTube через mpv.

---

## Что умеет

- Воспроизведение локальных треков (mp3, flac, opus, ogg, m4a, wav)
- Поиск и воспроизведение YouTube
- Плейлисты с возможностью перемещения треков
- Рейтинг треков (1–5 звёзд) и фильтрация по рейтингу
- Скачивание YouTube-треков через yt-dlp в ~/Music
- История воспроизведения (YT и локальная)
- Полноэкранный просмотр обложки
- Настраиваемые горячие клавиши
- Скриншоты через grim

## Структура файлов

### Состояние и логика

| Файл | Что делает |
|------|-----------|
| `PlayerState.qml` | Главный синглтон. Хранит всё состояние плеера: текущий трек, список, режим, плейлисты, историю. Управляет mpv через Unix-сокет (`/tmp/qs-player-mpv.sock`). Запускает все внешние процессы. |
| `Settings.qml` | Синглтон настроек. Хранит горячие клавиши, размеры панели, цвет акцента, настройки отображения. Читает/пишет `~/.config/qs-player/settings.json`. |
| `KeybindHandler.qml` | Обработчик клавиатуры. Принимает все нажатия, разбирает одиночные клавиши, последовательности (`dd`, `dt`, `tu`) и модификаторы. Вызывает методы `PlayerState` и `Settings`. |

### Главное окно

| Файл | Что делает |
|------|-----------|
| `Player.qml` | Корневое окно (`PanelWindow`). Управляет видимостью, анимацией появления, фокусом клавиатуры. Содержит весь layout и все оверлеи. |

### UI-компоненты (внутри панели, сверху вниз)

| Файл | Что делает |
|------|-----------|
| `ThumbStrip.qml` | Верхняя полоса с обложкой текущего трека, прогресс-баром, рейтингом звёздами и бейджом режима (LOCAL / PLAYLISTS / YOUTUBE / HISTORY). Клик — fullscreen обложка. |
| `TrackInfo.qml` | Название и исполнитель текущего трека. |
| `ControlsBar.qml` | Кнопки управления: shuffle, prev, play/pause, next, loop, mute, ползунок громкости. |
| `PlayerTabBar.qml` | Переключатель режимов: Local / Playlists / YouTube / History. |
| `YtSearchBar.qml` | Поле ввода для поиска на YouTube (видимо только в режиме YouTube). |
| `FilterBar.qml` | Поле фильтрации локального списка по названию (появляется по `f`). |
| `PlayerTrackList.qml` | Список треков с прокруткой. Показывает обложку, название, исполнителя, рейтинг, длительность, YT-бейдж. Текущий трек и курсор подсвечиваются отдельно. |
| `StatusBar.qml` | Нижняя строка: статусное сообщение, время позиции/длительности, прогресс-бар скачивания. |

### Оверлеи (всплывающие поверх панели)

| Файл | Что делает |
|------|-----------|
| `PlaylistPickerOverlay.qml` | Выбор плейлиста для перемещения трека. Навигация j/k или цифрами 1–5. |
| `CreatePlaylistOverlay.qml` | Создание нового плейлиста. Поле ввода имени + кнопки. |
| `DeleteConfirmOverlay.qml` | Подтверждение удаления трека (файл + метаданные). |
| `GotoOverlay.qml` | Переход к треку по номеру (`dt` → ввод числа → Enter). |
| `KeybindsOverlay.qml` | Справка по горячим клавишам (открывается по `e`). |
| `SettingsOverlay.qml` | Настройки: цвет акцента, переключатели отображения, редактирование горячих клавиш. |

## Данные и файлы

```
~/.config/qs-player/
  library.json      — локальная библиотека треков с рейтингами
  playlists.json    — плейлисты и их треки
  history.json      — история воспроизведения (YT + local)
  settings.json     — настройки и горячие клавиши

~/Music/            — директория сканирования (musicDir)
~/Music/meta/       — обложки и .info.json, скачанные yt-dlp
~/Pictures/qs-player/ — скриншоты
```

## Горячие клавиши (по умолчанию)

| Клавиша | Действие |
|---------|---------|
| `Space` | Play / Pause |
| `n` / `b` | Следующий / Предыдущий трек |
| `j` / `k` или `↓` / `↑` | Курсор вниз / вверх по списку |
| `Enter` | Воспроизвести трек под курсором |
| `l` | Включить/выключить loop |
| `s` | Shuffle (или `s` + `1–5` для рейтинга) |
| `m` | Mute |
| `1–9`, `0` | Установить громкость 10%–90%, 100% |
| `←` / `→` | Перемотка −10 / +10 сек |
| `Shift+←` / `Shift+→` | Перемотка −60 / +60 сек |
| `f` | Фильтр по названию |
| `r` | Сканировать ~/Music |
| `i` | Скачать текущий YT-трек |
| `t` | Переместить в плейлист (затем Enter или цифра) |
| `tu` | Создать новый плейлист и переместить |
| `u` | Создать плейлист |
| `q` | Удалить трек (с подтверждением) |
| `d` | Начало последовательности: `ds` — фильтр по рейтингу, `dt` — перейти к треку по номеру |
| `e` | Показать/скрыть справку по клавишам |
| `Shift+F` | Fullscreen обложка |
| `Shift+S` | Скриншот |
| `Ctrl+1–4` | Переключить режим: Local / Playlists / YouTube / History |
| `Esc` | Закрыть верхний оверлей |

Все клавиши можно переназначить в Settings (`SettingsOverlay` или `settings.json`).

## Зависимости

- [Quickshell](https://quickshell.outfoxxed.me/) — оболочка для запуска
- `mpv` — воспроизведение аудио (запускается с IPC-сокетом)
- `socat` — отправка команд в mpv через сокет
- `yt-dlp` — поиск YouTube и скачивание треков
- `ffprobe` (из ffmpeg) — чтение метаданных при сканировании
- `grim` — скриншоты (Wayland)
- `python3` — запись файлов настроек/библиотеки
- `bash`, `find`, `rm` — вспомогательные операции

---

## Запуск

```bash
quickshell -p ~/.config/quickshell/player
```

Открыть/закрыть окно плеера — через вызов из bar или другого компонента Quickshell, который переключает `playerWindow.playerVisible`.
